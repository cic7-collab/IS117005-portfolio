# IS 117 Portfolio: AI Careers Research

A student research project exploring growing job titles, day-to-day work, and career pathways across artificial intelligence and related technology fields.

## Live site

[Open the IS117005 Portfolio Research site](https://cic7-collab.github.io/IS117005-portfolio/)

## Research focus

- What do newer and fast-growing AI-related job titles mean in practice?
- What work, skills, education, and experience do employers expect?
- Which career paths connect software, data, AI research, and security?
- How do job outlook projections differ by country and research method?

## Run locally

```sh
npm install
npm run docs:dev
```

The site is built with [VitePress](https://vitepress.dev/). GitHub Actions builds and publishes `docs/.vitepress/dist` to GitHub Pages when changes reach `main`.

## Starting sources

- [U.S. Bureau of Labor Statistics: Data Scientists](https://www.bls.gov/ooh/math/data-scientists.htm)
- [U.S. Bureau of Labor Statistics: Computer and Information Research Scientists](https://www.bls.gov/ooh/computer-and-information-technology/computer-and-information-research-scientists.htm)
- [U.S. Bureau of Labor Statistics: Information Security Analysts](https://www.bls.gov/ooh/computer-and-information-technology/information-security-analysts.htm)
- [World Economic Forum: Future of Jobs Report 2025](https://www.weforum.org/publications/the-future-of-jobs-report-2025/)

The BLS figures are U.S. projections for 2024–34; WEF figures summarize surveyed employers' global expectations for 2025–30. These measures are not directly comparable.
